# M3.7 production database migration — 18 October 2026

**Approved by:** the product owner, in session, before the change. **Result: applied and verified.**

## Why it was urgent

Render auto-deployed `main` (prayer journal, pastoral care, safeguarding, guided meditation) before the production database had the matching migrations. `GET /api/v1/pastors` returned **500**, and signed-in prayer, care and safeguarding requests would have failed. Production then had 3 users and no prayers, so impact was limited.

## Migrations applied (all additive)

1. `20261017120000_prayer_journal`: new prayer columns, `updatedAt`, owner index
2. `20261017180000_pastor_profiles`: verification columns, `PastorProfile`
3. `20261017200000_care_requests`: `CareRequest`, `CareMessage`, enum
4. `20261017220000_care_safeguarding`: `CareReport`, `SafeguardingAction`, enum
5. `20261018090000_guided_meditation`: meditation columns, `AiUsage`

No table or column was dropped, renamed or rewritten.
