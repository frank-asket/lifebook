# LifeBook

Prototype of the LifeBook Christian wellness product: a marketing site and a mobile app that runs
entirely on local mock data (no backend in this phase).

## Apps

| Path      | Stack                          | Run                          |
| --------- | ------------------------------ | ---------------------------- |
| `landing` | Next.js 16, Tailwind 4         | `cd landing && npm run dev`   |
| `mobile`  | Expo SDK 57, Expo Router, RN   | `cd mobile && npx expo start` |

Node 22 is required by the Expo toolchain.

## Mobile scope

Seven-step onboarding, six-mood check-in, deterministic scripture retrieval from a fixed vetted
corpus, the five-step guided flow (scripture → reflect → meditate → pray → complete), five-day
journeys, library, journal, streaks and badges, community groups with local moderation, and a
persistent crisis-resource footer. State and analytics events are stored in AsyncStorage on the
device; no scripture is generated by the app.

## Status

Pre-release. The apps are built and verified by lint, typecheck and build, but no real user has
used them yet — the landing page recruits a first test group of five to ten people.
