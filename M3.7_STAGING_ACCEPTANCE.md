# M3.7 Staging Acceptance — 18 and 19 October 2026

**Result: PASS.** Every M3.7 acceptance criterion is met on staging. Isolation between members (criterion 2) is proven by the automated cross-member access test in PR #62, which replaced the manual account-B step. No bugs were found that block launch; four minor findings are listed below.

## Isolation (criterion 2)

Covered by **PR #62, "Cross-member access test across every API route"**, instead of a manual second account. Member A creates real private data over HTTP, including prayers with an answered note. Member B then calls **all 98 registered routes**:

- B gets exactly 403 or 404 on every route that names A's records.
- No response contains A's text or IDs.
- Every row A owns is byte-identical afterwards, including after B runs delete-all-prayers and deletes their own account.
- New routes fail the test until they are classified, so future endpoints can't skip the check.

This is stronger than the manual check it replaces. Only Clerk is replaced by a test double; controllers, guards, services and Postgres are real. The real Clerk path was exercised with account A above.

## Privacy

- **Encryption at rest:** the three new `PrayerEntry` rows stored `lbenc:v…` envelopes in `ciphertext` (172–204 chars), `answerNoteCiphertext` (96) and `meditationCiphertext` (2,964). No plain-text columns were used.
- **Database:** a read-only scan of all 31 public tables found none of the test markers or prayer phrases in plain text, before or after deletion.
- **Logs:** the API log contained none of the markers or prayer phrases.
- **After delete-all:** the three rows were removed from `PrayerEntry`, so deletion is real, not a soft delete. None of the 31 tables reference the three IDs, and none of them contain the marker text.

## Minor findings (not blocking)

| Finding | Suggested fix |
| --- | --- |
| Clicking "Mark as answered" while an edit is still saving does nothing, and nothing tells you. The typed note stays in the box and is easy to mistake for saved. | Queue the action, or show "Saving your prayer first…" |
| A guided meditation takes about 20–25 s, with only "Preparing…" shown | Explain the wait ("This can take up to half a minute"); measure in production |
| Every member sees both the France and Ghana crisis numbers | Expected while country is unknown; consider choosing by language or a country setting once the numbers are verified |
| Settings renders a hidden duplicate of some controls (two "Delete all prayers" buttons, two sets of onboarding links, one not visible) | Check the Settings layout; screen readers and tests may find the hidden copy |
| Prayer routes check the request body before authentication (400 "Invalid prayer request" without a token) | Harmless (no data); order auth first for consistency |
