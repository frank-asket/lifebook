# Database A (Transactional Relational Database - PostgreSQL)

Primary ACID-compliant relational database storing profiles, relationships, content structures, and relational state.

## Port
- `5432`

## Schemas & Migrations
Stores normalized relational tables:
- `users`
- `profiles`
- `streaks`
- `groups`
- `group_members`
- `prayer_requests`
- `discussions`
