# M3.8 — Accessibility pass (browser)

19 October 2026, on the local staging web app (signed in with the staging test account). This pass gets the real-device check (iPhone Safari, Android Chrome, VoiceOver, TalkBack) off to a clean start. It doesn't replace that check.

## Method

- **Automated:** axe-core 4.10 with WCAG 2.0/2.1/2.2 A and AA rules plus best practices, on 21 pages in **dark and light** themes: Home, Daily Word, the Bible pages (Study, Reader, Reading dashboard, Plans, My reading, Saved verses), Meditation and its history, Prayer, LivingWord, My Journey, Ask a pastor, Pastor space, Our pastors, Settings, Onboarding, Safeguarding and the welcome page. CSS transitions were turned off for the contrast checks, because the preview browser doesn't finish them and would otherwise report mid-transition colours.
- **Manual:** keyboard use of the "What's new" sheet (focus on open, focus trap, Escape, focus on close), visible focus rings, the skip link, the heading outline on each page, landmarks, and live regions for errors and progress.

## Found and fixed

| Issue | WCAG | Fix |
| --- | --- | --- |
| Text links ("Open", "See all"…) were 3.1:1 on dark cards | 1.4.3 Contrast | `.text-link` uses the theme accent: 5.6:1 light, 7.4:1 dark |
| Every page had the same browser title, which is also what screen readers announce on each navigation | 2.4.2 Page titled | Each page has its own localized title ("Prayer Sanctuary \| LifeBook", "Sanctuaire de prière \| LifeBook") |
| Bible Study category cards used `h3` before any `h2`, inside buttons | 1.3.1 Info and relationships | Card titles are no longer headings; they look the same |
| Closing the welcome or "What's new" sheet left focus on the page body | 2.4.3 Focus order | Focus returns to what opened the sheet, or to the page content |

Tests guard the first two: `apps/web/test/accessibility.test.cjs` checks the titles, and checks that the accent and muted text meet 4.5:1 in both themes.

## Already good

Skip link on every page; one `main` landmark; labelled navigation; visible focus rings; the sheets are labelled, keep focus inside, and close with Escape; errors use `role="alert"` and progress uses live regions; the reader's controls are labelled; 44px touch targets; Reduce Motion respected.

## Left for the real-device check

- VoiceOver (iPhone) and TalkBack (Android) through the smoke-test journeys, in English and French.
- Text enlarged to 200% and the iOS largest text sizes.
- The Clerk sign-in and account screens, which Clerk renders and we can only style.
- Titles on the welcome and sign-in pages are English only, because they're set before the language is known.
