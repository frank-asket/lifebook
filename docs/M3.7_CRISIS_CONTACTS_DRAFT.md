# Crisis contacts — draft for verification

**Status:** DRAFT, not for production. Researched 17 October 2026 from public sources. **Every number must be verified by a person in each country before LifeBook shows it.**

**Where this appears:** when a prayer suggests someone may be at risk (self-harm, harm to others, abuse), the Prayer Sanctuary shows a short, calm message with these contacts instead of generating a meditation. The screen shows **2–3 contacts per country**: the emergency number first, then a listening or crisis line, then a specialist line where relevant. More is not better in a crisis.

**How to use this list:** for each row, call the number (or have a local contact call it), then fill in the *Verified* columns. Strike out anything that fails. Rows marked **Hold** must not ship until the conflict is resolved.

## Rules for the app (proposed)

1. Show contacts only for the reader's country (from settings or language), with **112 always first**.
2. Every contact carries `verifiedBy`, `verifiedOn` and a `nextCheck` date (suggested: every 3 months). An expired contact is hidden, never shown stale.
3. The crisis message never diagnoses, never promises an outcome, and never asks the person to keep using the app first.
4. The prayer stays private: nothing is escalated, shared or reported.
