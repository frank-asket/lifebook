## Risks

| Risk | Mitigation |
| --- | --- |
| Clerk production setup slips | Continue source and content preparation; final identity, invite-only, retained-account and signed-in acceptance remain blocked. |
| Too few reviewed Daily Word entries | Keep launch gated until reviewed entries cover the actual first 30 launch days; an older rotation is not approval. |
| Vercel deploy limit on release day | Decide the plan first; otherwise batch merges and deploy once. |
| An unverified crisis number shown to someone at risk | The gate blocks launch until each number has been called and confirmed. |
