# M3.8 — Web visual matrix

19 October 2026, for the product completion plan's "verify every route at 320/390/768/1440 px, both themes and languages". Run on `fix/web-visual-matrix`, which sits on PR #58 so it includes the new Bible search, LivingWord and My Journey pages.

## Setup

- **Web:** the local dev server, signed in with the staging Clerk test account.
- **API:** the local build against a **throwaway PostgreSQL 17** with every migration (PR #58's two included), the repo's study and meditation seeds, and a small synthetic fixture: two published pathways (one with a deliberately long title), and three English plus two French approved teachings on a placeholder media host. No staging or production data was copied.
- **Harness:** a temporary page loads each route into four same-origin frames, 320, 390, 768 and 1440 px wide, so CSS media queries respond to each width. In every frame it checks:
  - horizontal overflow, and which elements stick out;
  - text clipped by its container;
  - tap targets under 24 px (WCAG 2.5.8);
  - visible error states;
  - exactly one visible `h1`.

  axe-core 4.10 ran WCAG 2.0–2.2 A/AA at 390 px with transitions off. Both checks were proven on planted failures: a 600 px link at 320 px, and 1.26:1 text in dark mode.

## Found and fixed

| Issue | Where | Fix |
| --- | --- | --- |
| **Crash:** "Invalid hook call" on every visit | `/bible/read` (PR #58) | The scroll-to-verse effect was nested inside another effect; moved to the top level. Pushed to PR #58. A new CI test, `hooks-placement.test.cjs`, fails on any hook outside a component's or hook's top level. |
| New members saw "Your recent reading could not be loaded" | Home; the mobile Bible tab | Both API clients treated a 200 with an empty body (NestJS's `null`) as an error; it is now `null`. Also on main. Pushed to PR #58 with tests. |
| Standalone links 16–22 px tall: "View all", "← All Bible studies", "← All pathways", "← All teachings", "Meet our pastors", "Update choices", meditation links | 10 routes | Standalone `a.text-link` and meditation links are at least 44 px tall; links inside running text are unchanged |
| A **Try again** button under "Only LifeBook editors can publish teachings", which can never succeed | `/livingword/editor` | A 403 now shows a plain explanation and points to the library, with no retry |
